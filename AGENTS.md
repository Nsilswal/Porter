# Working agreement

- Deliver changes through small, coherent pull requests so individual changes can be reverted.
- The user authorizes opening PRs and merging them to `main` automatically when review is complete and relevant tests pass. Review every PR before merging; test its committed state, including required checks.
- Resolve actionable review findings before merging. Record what was tested and any remaining limitations in the PR.
- Maintain a high code-quality bar and make related cleanup when it improves clarity or correctness. Keep unrelated work out of each PR.
- Follow `docs/product-prd.md` for accepted product scope and `docs/session-handoff.md` for current implementation state. Do not repeat settled discovery questions.
